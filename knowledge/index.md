# Knowledge Base Index

This knowledge base supports the Gap Inc. Media Analytics Dashboard project, targeting the Analyst, Media Analytics role at Gap Inc. It covers brand performance, competitive landscape, marketing strategy, and sourcing operations.

## How to Query This Knowledge Base

1. Start here to identify the most relevant wiki page for your question
2. Read the relevant wiki page(s) in `knowledge/wiki/`
3. Cross-reference specific facts, quotes, or figures in `knowledge/raw/` source documents
4. Synthesize across multiple sources — do not rely on any single document
